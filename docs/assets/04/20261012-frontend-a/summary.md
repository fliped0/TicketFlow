# 前端注册登录与目录选票（2026-10-12）

## 交付与边界

Vue 独立前端已实现注册、登录、当前账号、退出及刷新身份验证；公开活动关键词/城市/分类筛选与分页；活动详情、场次/票档选择、服务端价格与库存、选票摘要，以及登录后返回并恢复选票。已售罄、未开售和已停售票档禁用；活动文案文本渲染，错误可重试，请求取消与旧响应隔离。

未实现网页下单、支付、订单列表/详情、取消/退款及未知交易恢复，页面明确禁用下单。这是最小前端计划的查询与身份阶段，不能宣称完整购票闭环完成。Java 源码、HTTP 契约、CORS 与 Flyway 不变，既有后端/Agent 测试未重跑或累加，未访问模型、Redis 或 MQ。

## 开发演示与历史问题

开发库通过现有 AdminInitializer 初始化随机本机演示管理员。凭据由 Windows 当前用户加密，保存在忽略的 config/local/frontend-demo-admin.xml；不在聊天、源码或报告中输出密码。三个演示活动、各一个七天后场次及两档 99/199 元、20 张库存通过管理员 HTTP API 建立。数据准备脚本本身只使用已有管理员，不自动提权，不执行 SQL。

第一次模拟浏览器集 6/8：失效身份测试用未命名 `role=status` 定位，同时匹配登录提示和活动加载提示，导致两种视口定位失败。为登录状态增加可访问名称并精确定位后完整 8/8；未跳过场景或弱化文本断言。

首次演示脚本控制台中文受 Python 默认编码影响显示异常；JSON 通过 UTF-8 发给 API，资源本身正确。显式设置子进程输出编码后复跑确认同批资源及正确中文输出。Element Plus 懒加载基础样式覆盖主题导致按钮回到蓝色，增强主题选择器后重新构建并检查截图。保留执行环境 NO_COLOR/FORCE_COLOR 提示。
