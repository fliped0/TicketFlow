# TicketFlow 开发进度

更新：2026-09-30。开发基线为 Java 17、Maven 3.9.12、MySQL 8.0.45。

| 批次 | 内容 | 状态 |
| --- | --- | --- |
| 1 | 工程骨架、Flyway 迁移、用户认证、健康检查 | 已实现；统一分层重构完成，19 项测试通过 |
| 2 | 活动、场次、票档、库存建档、发布上下架和冻结 | 已实现；27 项当前测试通过 |
| 3 | 幂等执行器、下单、限购、库存扣减与归还 | 未实现 |
| 4 | 模拟支付、取消、超时关闭、退款 | 未实现 |
| 5 | 管理统计、对账、恢复、并发与性能 | 未实现 |

第一批提供 3 个用户 API 和 1 个健康接口。第二批提供 11 个管理员目录接口。订单与统计管理接口仍待后续批次；存在迁移表不代表业务已完成。

第二批新增 4 个公开目录查询和 11 个后台目录接口。创建票档同时初始化库存并记录审计；下单扣减库存属于第三批。目录与认证的当前完整回归为 9 项单元测试和 18 项真实 MySQL / HTTP 集成测试。第三批开始实现交易执行器、幂等、下单和限购；下单与下架竞争等跨模块场景届时验证。

后端现采用一套共享的 controller、service、mapper、model 分层，model 下区分 dto、vo、entity；config、security、common 承担配置、安全与通用基础能力。结构决策和依赖规则见[架构与编码规范](架构与编码规范.md)。

每批交付包括代码、接口文档与真实测试结果，通过测试后提交和推送。远端认证未完成时明确区分本地提交与远端备份。
