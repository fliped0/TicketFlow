# 异步抢票网页验收

日期：2026-10-14。范围见[接入计划](../../../13_异步抢票前端计划.md)。

## 实现

场次新增 `purchaseMode`，公开与管理目录一致，缓存结构版本隔离旧数据。前端按模式提交同步订单或异步请求；无法识别模式时暂停提交。异步受理前保存原键及票档，受理后仅查询原请求，未知受理由用户显式原键恢复。共享跨标签页锁与未决交易保护，支持刷新和原账号重新登录；结果成功衔接现有订单及模拟支付。

轮询仅在页面可见且在线时运行，正常至少间隔 2 秒，错误递增退避至 30 秒，并尊重 Retry-After。处理时间已过仍以服务端终态为准，不把超时显示为失败。用户清除站点存储或换浏览器后不能自动找回原键；本批不提供处理中请求取消。

## 开发中发现及修正

首次中间件连接超时，用户确认服务器未开机并启动后恢复连接。首次类型检查修正了未使用导入与测试 mock 的 Promise 类型；首次新增账号隔离单元测试错误地先赋用户再切换令牌，触发既有身份清理逻辑，已改成先切换令牌再建立验证身份。首轮浏览器 48/50，失败为两条旧 ASYNC_REQUIRED 文案断言；保留业务断言，更新为现在的“刷新场次后重新确认”，全套重跑 50/50。
