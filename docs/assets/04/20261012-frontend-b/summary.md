# 前端购票、模拟支付与原键恢复（2026-10-12）

## 实现与范围

新增独立下单和模拟支付确认弹窗、我的订单（状态筛选/分页）、订单详情（成交快照/支付记录/支付截止和倒计时），以及全局已确认操作结果/恢复入口。服务器仍控制价格、库存、资格和期限；Java 源码、API/OpenAPI、历史迁移和 CORS 均未改。

发送前按当前 origin/用户持久保存原请求键、固定动作/对象及摘要，不存 JWT/密码。本页忙状态和 Web Locks 协调重复点击/跨标签页执行。成功回执核对订单/操作/金额/支付编号，明确业务拒绝关闭尝试；网络未知、5xx、401、429、键冲突及错误回执不生成新键。恢复只重放此前明确确认的原操作。记录损坏或不能安全保存时暂停写入，UNKNOWN 不能直接删除/覆盖。

倒计时参考 HTTP Date 校准显示，后台可见的待支付详情每 10 秒只读刷新；客户端到期显示不能替代后端检查。查到当前订单已支付也不自动抹去未决操作，仍需原键拿回原回执。前端暂未提供取消/模拟退款按钮，已有相关状态与记录可查询；Agent/异步抢票及生产部署不在本批范围。

## 问题记录与边界

- 首次新增测试类型检查发现测试代码错误引用 Pinia 内部属性，改为显式创建 Pinia/身份后通过；未放宽业务断言。
- 首轮工具链及浏览器功能检查通过后，补验实际跨标签页协调，19/19 和 26/26 通过；不把早期 18/18、24/24 再累加为更多独立用例。
- 固定弹窗整页截图会拼入视口外固定元素，改为弹窗拍当前视口、其他页面回到顶部拍整页。最终八张截图检查无横向溢出，未据此修改业务计分。
- 扩展首轮移动端注册在路由未完成时提前填入密码，之后被页面切换清空，客户端校验拒绝且未发送注册请求。增加“创建账号”表单就绪断言后完整 14/14，未增加重试或删掉场景。实际检查该失败截图和客户端状态，并保留失败统计。
- 检查锁定 Playwright 的实现发现自动失败页面文本快照会包含密码输入值；真实 runner 禁用此快照，继续保留错误断言、截图和统计。之前失败的本机诊断快照未提交，汇总不含密码/JWT，截图中的密码输入始终掩码。
- 浏览器 localStorage 同步保存与刷新恢复已验证，未宣称操作系统断电/磁盘恢复。清除站点数据、换浏览器或未决期间切换代理目标不能自动保证原键恢复，须先核查订单。当前取消/退款仅作为测试收尾 API 操作，不作为其网页入口已经完成的证据。
- 既有 Java/Agent 回归未重跑、未累加；无真实扣款或模型请求。NO_COLOR/FORCE_COLOR 执行环境提示保留。
