| --- | --- | --- |
| 1 | 工程骨架、Flyway 迁移、用户认证、健康检查 | 已实现；统一分层重构完成，19 项测试通过 |

第一批提供 3 个用户 API 和 1 个健康接口；第二批新增 4 个公开目录与 11 个管理员目录接口；第三批新增 3 个下单及本人订单查询接口，共 22 个已实现 HTTP 操作。支付、取消、关单、退款以及订单与统计管理接口待后续批次；存在迁移表不代表业务已完成。

第三批以 JdbcTemplate 实现 TradeExecutor、OrderApplicationService、InventoryService、DatabaseClock 及相应 Mapper，沿用统一分层与单事务 READ COMMITTED。先锁当前用户并重新检查 enabled，随后处理请求键；业务拒绝回滚保存点并提交 REJECTED，系统与数据库异常整笔回滚。下单按父目录到库存有序锁定，在锁后用新 SQL 取 UTC 时间，订单、资格、库存和流水共同提交。本人查询保留成交快照，他人订单与不存在统一 404。

当前完整回归为 12 项单元测试和 33 项真实 MySQL / HTTP 集成测试，共 45 项，0 失败、0 错误、0 跳过。第三批新增 3 项规则单测和 15 项交易集成测试：保存点撤销、五处写入故障全回滚、SQL 唯一冲突、有限锁重试与真实锁超时、20 次同键并发重放、同键异参、跨票档限购、最后一张票竞争、下架双方先持锁、锁后跨开售/停售时间、锁内账号禁用复查，以及本人查询与输入类型校验。

接口文档为 0.3.0；测试范围、命令、实际结果与源码哈希见[批次 3 测试报告](assets/04/20261001-order/summary.md)。校验 OpenAPI 时修复了旧目录请求体的空 schema 引用，并去掉 GET 请求体。既有迁移 V1 未改动。

批次 4 实现模拟支付、取消、超时关单与退款，并完成资格及库存归还；本批到期订单保持 PENDING 和占用，尚未提供自动释放。1000 用户/100 工作线程/100 张票的三轮实验、进程终止恢复和性能验收仍留后续批次，未宣称完整 V1 验收通过。

批次 3 交付状态：代码、文档、测试证据已提交，功能提交为 `17b180f`；2026-10-01 经用户明确授权后已推送至 GitHub origin/main。
