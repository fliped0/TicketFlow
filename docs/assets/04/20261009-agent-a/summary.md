## 2. 覆盖范围

六项工具为活动搜索、活动详情、场次列表、票档列表、本人订单列表、本人订单详情。真实联调创建独立测试活动与 12,345 分票档、容量 2，一笔在途订单后可售量为 1；逐项对照 Java 直接查询结果核实对象、分页、价格和状态。测试夹具由独立测试客户端创建；Agent 仅发送 GET，不拥有管理员、建单或交易写工具。

79 项确定性测试使用 MockTransport 的受控 Java 响应和固定模型输出，覆盖认证失效/禁用、他人订单拒绝、会话归属/过期/删除/忙状态、真实异步并发容量限制、原身份透传、BIGINT/分页/未知参数、恶意 URL 与写工具、批量调用前整批校验、模型异常及错误输出、循环与次数上限、总超时、上下文和收发大小边界、空结果/畸形契约/分页不一致、重定向拒绝、数据裁剪、整数金额精度、日志脱敏及 Java schema 漂移。模型试图根据不可信材料调用退款时仍被白名单拒绝。

9 组真实 HTTP 检查包含六项查询、跨用户订单拒绝、演示聊天及跨用户会话拒绝、写工具与非法 JWT 拒绝。试图调用取消工具返回 422，后端订单仍为 PENDING；最后取消订单仅由夹具清理代码直连 Java 完成。该联调不依赖 Redis/RabbitMQ，未触碰云端中间件。

## 3. 环境、失败与中间结果

Python 3.12.10；项目隔离环境 `agent/.venv`，精确依赖见 `agent/uv.lock`。FastAPI 0.143.0、Pydantic 2.14.0、HTTPX 0.28.1、Uvicorn 0.54.0、pytest 9.1.1、Ruff 0.16.10。现有 Java 运行包与 MySQL 复用既有本机配置；包哈希见 environment.json。

首次 uv 使用系统缓存遇到文件权限错误，改用仓库忽略目录 `.tools/uv-cache`；沙箱网络下载被拒绝后，通过正常授权在项目环境安装依赖。首次沙箱 pytest 无输出并被中断，不计通过；随后在普通执行环境完整通过 67 项。增加边界检查后 74 项与首轮真实联调通过；最后补充空结果、契约、上下文和不可信材料测试后，79 项与最终真实联调通过。初轮 Ruff 报告格式/导入问题，修复后最终全通过。

Starlette TestClient 发出一条 HTTPX 弃用警告，未过滤或隐藏；当前锁定组合执行成功，后续依赖升级须重新验证。最终没有被跳过的产品断言，也没有以简单重跑掩盖产品失败。
