## 新增覆盖

- 登录入口、纯文本显示不可信查询内容、聊天“确认”不执行交易、撤销卡片不取消订单。
- 提交前持久保存；保存失败、记录损坏、原购票结果未知或其他标签页持锁时不发送执行请求。
- 核对窗口对应的确认编号变化时拒绝执行，需重新核对。
- 浏览器丢失已提交的回执后，原记录保留，阻止新购票；刷新后 GET 原确认成功，无第二次执行。
- 服务端 UNKNOWN 按原确认编号 recover；PENDING 不调用 recover。
- 会话失效提示显式新建，不自动重发原问题。
- 真实退款丢失响应后切换账号，其他账号页面不显示记录，读取原确认返回 404；原账号重新登录查询成功，退款编号与首次提交相同。
- 规则出处可展开；桌面/手机无水平溢出。已检查取消完成桌面截图与退款恢复手机截图。
