# Agent 网页接入

2026-10-13。本批在既有 Vue 前端接入已实现的 Python Agent，复用 Java 身份与交易服务。

## 交付范围

1. 登录保护的助手入口，直接活动/本人订单/退款规则查询，自然语言提问及显式新建会话。
2. 文本查询卡、可追溯规则出处、有效活动与订单详情链接；区分直接查询、固定指令演示和模型模式。
3. 取消/全额模拟退款确认卡，核对最新状态后独立确认；聊天与模型输出不触发执行。
4. 执行前持久保存确认编号，刷新与原账号重新登录恢复；GET 查询结果，UNKNOWN 按原确认恢复。
5. 助手和原购票流程共享按用户的跨标签页锁；未知结果或存储损坏阻止新交易。其他账号不展示或访问原记录。
6. 桌面与手机浏览器回归，真实 Java/Python/MySQL 联调及截图证据。

## 边界

- 本机开发代理，不新增公网部署。Java 执行交易，Python 维护确认及原幂等键，浏览器只保存恢复入口。
- 仅取消与模拟退款通过助手确认；下单与模拟支付沿用已有页面。
- 页面会话不跨刷新保存，无多轮指代记忆；新建会话不会删除交易确认。
- 自动验证使用 demo 模式，不调用收费模型；原有 gateway 配置可供交互使用，模型效果沿用历史报告，不声称本次重测。
- 清除浏览器存储或更换浏览器后不能自动列出历史确认，需先核查订单，不能盲目重复操作。
